# Shir0o Organization Standards & DevOps

This repository hosts global defaults, agent instructions, and automation templates for all repositories owned by `@Shir0o`.

## Structure

- `.github/`: Default community health files (`CODEOWNERS`, `SECURITY.md`) used as fallbacks across all Shir0o repos.
- `templates/`: Central source of truth for `AGENTS.md`, `dependabot.yml`, `ci.yml`, and branch protection rulesets.
- `apply-standards.sh`: Idempotent script to apply standards across all repositories under `~/`.

## Usage

### Preview changes (Dry Run)
```bash
./apply-standards.sh
```

### Apply standards to a specific repository
```bash
./apply-standards.sh --apply --repo attd
```

### Apply standards to all repositories and create PRs
```bash
./apply-standards.sh --apply
```

## How It Works

1. **`AGENTS.md`**: Generated by concatenating `templates/base-agents.md` with each repository's local `PROJECT.md`.
2. **DevOps files**: Synchronized from `templates/` based on repository tier (Tier 1 vs Tier 2) and framework (Flutter, Node, Python, Godot).
